# Gender Norms and Subjective Well-Being

This project studies the relationship between gender norms, household responsibilities, and subjective well-being using data from the World Values Survey (WVS). It applies binary dependent variable models to estimate how gender-related beliefs and responsibilities are associated with reported happiness.

## Research Question

Are gender norms and household responsibility beliefs associated with subjective well-being?

## Data

The analysis uses Wave 7 of the World Values Survey. The dataset is available from the WVS website: https://www.worldvaluessurvey.org/wvs.jsp.

## Methods

- Descriptive statistics and exploratory analysis
- Binary outcome modeling
- Logit, Probit, and Linear Probability Model specifications
- Discussion of identification assumptions and interpretation of marginal relationships

## Main Output

The repository includes:

- `APS2 Micro IV 24.2.Rmd`: reproducible RMarkdown analysis
- `APS2 Micro IV 24.2.R`: R script version of the analysis
- `APS 2 Micro 4.docx`: final report

## Reproducibility

Download WVS Wave 7 from the official WVS website, adjust the data path in the script if needed, and run the `.Rmd` file in RStudio.
