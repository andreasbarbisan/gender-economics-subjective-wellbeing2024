# Gender Economics and Binary Dependent Variable Models

This project explores the influence of gender identity on subjective well-being using data from the World Values Survey (WVS). It focuses on the relationship between household gender responsibilities and perceived happiness, analyzing how these dynamics affect well-being. The analysis uses binary dependent variable models and socioeconomic and cultural explanatory variables.

The repository includes the RMarkdown code and the Word report. The dataset is available from the WVS website at https://www.worldvaluessurvey.org/wvs.jsp; the project uses WVS Wave 7.

## Project Structure

### 1. Research Question

- **Description:** The project defines a research question in gender economics to investigate the relationship between gender identity and subjective well-being using global WVS data.
- **Objective:** Provide a broader understanding of how gender identity, especially in the context of household responsibilities, influences subjective well-being.

### 2. Microeconomic Theory

- **Description:** The project develops a microeconomic theory based on models such as Akerlof and Kranton (2000) on identity and utility. The theory is adapted to analyze the impact of gender norms on subjective well-being.
- **Objective:** Develop a coherent theoretical model that links gender identity to well-being and leads to a testable economic hypothesis.

### 3. Descriptive Data Analysis

- **Description:** The project presents descriptive statistics and charts for key variables, including happiness responses and perceptions of gender roles.
- **Objective:** Provide an initial view of the data and identify possible relationships between gender identity and well-being.

### 4. Economic Hypothesis Test

- **Description:** Binary regressions are estimated using models such as Logit, Probit, and LPM, with justification for the explanatory variables. Identification assumptions and results are discussed.
- **Objective:** Empirically evaluate the hypothesis about the impact of gender identity on subjective well-being and choose an appropriate model for robust analysis.

### 5. Code Organization and Documentation

- **Description:** The code is commented and structured to reproduce the analysis steps, including data preparation, descriptive analysis, and regressions.
- **Objective:** Support validation and replicability of the results.

## Requirements and Execution

This project was developed in R, using packages for survey data analysis and binary dependent variable models. To run the code, download the WVS data files and follow the instructions in the script.
